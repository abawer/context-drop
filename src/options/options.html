Settings

Your data

Contexts are stored locally in this browser profile. Nothing is sent anywhere until you attach it to a chat.

How the attach works

  1. Context Drop looks for the page’s file picker and hands it your file.
  2. If the page has no picker yet (Google AI Mode), it opens the “add files” menu first.
  3. If that is ignored, it drops the file onto the chat box.
  4. If the site still refuses, the text goes into the prompt.

Sites change often. If attaching stops working, reload the tab once so the extension picks up the latest page structure.

Binders

Binders group your contexts by topic. Create a binder, then file contexts under it. Right-click saved chats and web text start unfiled; move them into a binder from their context card below.
